# My Planner (الإصدار 3.1)

تطبيق أندرويد شخصي فيه أربعة تبويبات:

- **المهام:** مهام رئيسية مع مهام فرعية، تعديل وحذف، تاريخ استحقاق اختياري.
- **الملاحظات:** نص وتسجيل صوتي وصور ورسم، كلها بالترتيب الذي تريده (تكتب فوقها أو تحتها).
- **التقويم:** أحداث وروتين مع تكرار (كل يوم، أيام محددة، كل عدة أيام، شهريًا) وتذكيرات بإشعارات.
- **التركيز:** 25 دقيقة دراسة و5 دقائق استراحة مع إشعار عند الانتهاء.

وأيضًا: العربية والإنجليزية (من القائمة ☰ ← الإعدادات)، الوضع المظلم والمشرق، اهتزاز خفيف عند إنهاء المهام، احتفال صغير عند إنهاء مهمة رئيسية، وودجت تقويم للشاشة الرئيسية.

كل البيانات محفوظة على الهاتف.

## رفع هذا الإصدار على نفس الـ repository

1. (للأمان) أنشئ Release باسم v2 وأرفق فيه الـ APK الحالي قبل أي شيء.
2. افتح الـ repository ثم **Add file ← Upload files**.
3. اسحب من هذا المجلد: `www` و`native` و`scripts` و`.github` و`debug.keystore` و`package.json` و`capacitor.config.json` و`.gitignore` و`README.md`. الملفات التي بنفس الأسماء تستبدل القديمة، والقديمة تبقى محفوظة في سجل التعديلات.
4. اضغط **Commit changes**.
5. افتح **Actions** وانتظر نحو 6 دقائق حتى تظهر علامة ✅، ثم نزّل **MyPlanner-APK** من قسم Artifacts.
6. فك الضغط وثبّت `app-debug.apk`.

إذا لم يُستبدل ملف `.github/workflows/build-apk.yml`، افتحه من GitHub واضغط أيقونة القلم، والصق محتوى الملف الجديد مكان القديم، ثم **Commit changes**.

## إذا ظهر ⚠️ برتقالي في Actions

يعني أن البناء مع الودجت فشل، فبنى GitHub النسخة بدون الودجت تلقائيًا. التطبيق يعمل كاملًا بدونه. أرسل لي نص الخطأ من خطوة **Build APK (with widget)** لأصلحه.

## الودجت

بعد تثبيت التطبيق: اضغط مطولًا على فراغ في الشاشة الرئيسية ← **الودجت** ← **My Planner**. يعرض أحداث اليوم ويتحدث كلما غيّرت التقويم أو فتحت التطبيق، وبالضغط عليه يفتح التطبيق.

## ملاحظات

- الإشعارات والتسجيل الصوتي يطلبان إذنًا من الهاتف عند أول استخدام.
- ملف `debug.keystore` يثبّت التوقيع، فكل تحديث ينزل فوق القديم ويحتفظ ببياناتك. إذا ثبّتَّ نسخة قديمة بُنيت بدونه، احذفها مرة واحدة قبل تثبيت هذه.
- تذكيرات التقويم تُجدول للـ45 يومًا القادمة وتتجدد كلما فتحت التطبيق.
- واجهة التطبيق كلها في `www/index.html`. عدّله وارفعه وسيُبنى APK جديد تلقائيًا.
- مجلد `android` يُنشأ أثناء البناء، فلا ترفعه.

## محتويات المجلد

```
www/index.html                    التطبيق كله
native/                           ملفات الودجت (أندرويد)
scripts/                          سكربتات البناء
.github/workflows/build-apk.yml   يبني الـ APK على GitHub
debug.keystore                    مفتاح توقيع ثابت
package.json, capacitor.config.json
```
